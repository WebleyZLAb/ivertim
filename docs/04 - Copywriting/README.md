# Copywriting

Ovaj folder sadrži cjelokupan copywriting blueprint set za Ivertim: sistem komunikacije i final copy za svaku stranicu/uslugu. Sve je vodio vlasnik kroz ChatGPT sesije prije uvođenja u ovaj repo (2026-07-23).

Autoritet: `README.md` (root) → `docs/00-strategy.md` / `docs/01-branding.md` → ovaj folder. Ako nešto ovdje protivrječi strategiji ili brendingu, strategija/branding imaju prednost.

2. Page-level blueprintovi — jedan po stranici sajta:

## Status (2026-09-03)

Cijeli set je označen "Approved" po fajlu, ali je pisan prije poslovnog pivota (vlasnik odlučio da su stvarne usluge: 1. uslužno rezanje/kantovanje/bušenje, 2. namještaj po mjeri — vidi `CLAUDE.md`). Revidirani su: `00 - Communication System` (na v1.1 — §6/§7/§13, osnovni ton-dokument je najduže ostao neusklađen jer njega niko direktno ne "čita" kao page copy), `Services-Landing-Blueprint` (na v1.1), `Home-Blueprint` (na v1.1 — Hero, Usluge i §5 globalna pravila; prvi prolaz 2026-09-02 je dirao samo Usluge i ostavio Hero i §5 u kontradikciji, ispravljeno 2026-09-03), `Process-Blueprint` (na v1.1 — dodat §10a jer originalnih šest koraka, sa montažom, opisuje samo namještaj po mjeri), svih 6 mini blueprintova (napomena o novoj ulozi), i dodan je nedostajući `Cutting-Service-Blueprint`. Ostali page-level blueprintovi (Projects, Advice, Contact) nisu sadržajno vezani za konkretnu listu usluga i nisu mijenjani.

Cijeli set i dalje čeka: implementaciju kao stvarni sadržaj na sajtu (dev hold je i dalje na snazi — vidi `CLAUDE.md`) i, nakon toga, pretvaranje u dedicated Claude Code skill za voice/structure/content pravila.
